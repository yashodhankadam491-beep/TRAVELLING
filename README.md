# ExploreMyVillage 🌾

## Sustainable Rural Tourism & Local Economy

ExploreMyVillage is a modern, responsive frontend website designed to connect visitors with rural destinations, local businesses, artisans, traditional food, culture, and authentic experiences.

The project is built as a **frontend-only website**. No backend code is included.

## ✨ Features

- 🔐 Login and registration interface
- 👤 User profile display after login
- 🚪 Logout and account switching
- 🗺️ Rural destination discovery
- 🔎 Search and category filtering
- 📍 Destination details and local information
- 🏡 Local businesses and artisan experiences
- 📱 Responsive mobile-friendly interface
- 🍔 Mobile hamburger navigation
- 🛡️ Safer DOM rendering without injecting destination data as raw HTML
- ⚡ Efficient destination card rendering
- 💾 Frontend demo account and visit-request storage using browser `localStorage`
- 🌐 No backend or database required to run the demo

## 🚀 Run the Project

No installation or backend server is required.

1. Clone or download the repository.
2. Open `index.html` in a modern web browser.
3. Register or log in using the frontend interface.
4. Explore destinations and use the available interactive features.

For the best experience, run the project through a local static server such as VS Code Live Server.

## 🔒 Frontend-Only Security Note

This project includes safer frontend practices such as DOM-based rendering and input validation. However, browser-only authentication and `localStorage` are **not a replacement for production authentication**.

For a future production deployment, authentication, user accounts, payments, and sensitive data should be handled by a secure backend and database. No backend has been added to this repository at this stage.

## 💳 Payment Note

The current project does **not** claim to verify real payments. Any booking/visit-request functionality is treated as a frontend demonstration and should not be considered a real payment confirmation system.
